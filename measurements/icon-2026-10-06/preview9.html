Github Flow · 菱形由流组成

换的是主次：不再"git 的标 + 一条流线"，而是让流本身长成那个菱形——五条长短不一的横条（信息流的条目）摞起来，外轮廓正好是 git 那个菱形。远看是 git，近看是一条条流过去的东西。最上面那条是绿的（最新/最热）。

我的推荐：方案 1。它把两件事压进了一个动作里，而不是把两个图形叠在一起——16px 上它退化成"一个菱形"（git 身份还在），256px 上你看到的是一条条流（信息流身份也在）。这种"大尺寸看到细节、小尺寸剩下剪影"的做法，是图标设计里最稳的一条路。

方案 2 把每一条往右下错一点，动感更强、更像"在流"，但菱形会歪；方案 3 是保守版：菱形轮廓还在，三条流从它中间穿过去。

这一版凭什么不是"又一个丑的"

① 一个动作说两件事：前几轮都是把两个图形叠起来（菱形 + 流线、菱形 + 分叉），叠出来的东西在任何尺寸下都要"同时看两个形状"，所以又乱又难认。这一版只有一个形状——横条；菱形是这些横条长短变化的结果，不是另外画上去的。

② 尺寸变大时信息变多，变小时信息变少，但都不散：五条横条在 16px 上糊成一个实心菱形，那是它能扛住任务栏的原因；在 256px 上你才看得到"一条一条"和那条绿色。

③ 宽度是算出来的，不是随手给的：菱形的数学是 |x-512| + |y-512| ≤ 370（半对角线 370），所以每一行的半宽 = 370 减去它到中心的距离。五行的宽度因此是 268 / 504 / 740 / 504 / 268——这个阶梯就是菱形的边。
