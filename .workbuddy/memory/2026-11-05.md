### 关键实测发现（以后别再凭印象说）
- **静默漏采**：14 个按天 cursor 里有 4 天命中 >1000（10-21:1216 / 10-22:1165 / 10-23:1081 / 10-24:1031），
  各被截断在 1000，共漏 493 条，而 `cursor.exhausted=1`。根因 `ingest.rs:80`：`page > max_pages → exhausted=1`。
  官方 + `measurements/p11.json` 确认 Search 每次查询硬上限 1000 条（还有「最多从 4000 个仓库返回」）。
- **曲线覆盖只有 0.78%**（signal 169 行 / 90 仓库，每仓库仅 1–3 周）。
- **`stargazers/history` 是 2026-09 新官方端点**（不是野端点）：每页 30 周、page≤100、
  `days` 从 Sunday 起、**周/日边界不保证对齐 UTC**、公开仓库无需认证、有 422 防刷。
  → `rank.rs:9` 假设 UTC 周一、`rank.rs:49` 拿 `days>0` 个数当"已过天数"，两处都会算错，且现有单测测不出。
- `GET /repos/{full}` 实测 **87 字段 / 7123 B**，现有 `ApiRepo` 只解析 11 个；
  `fork/parent/source`（判克隆仓）、`node_id`（GraphQL 批量必需）、subscribers/network/pushed_at/license 全丢了。
- `iso_to_epoch` 只取 ISO 前 10 位 → 全库 created_at 都是 00:00:00。
- 项目内 SQLite 是 **3.46.0**（`libsqlite3-sys 0.30.1` bundled，build.rs 有 `-DSQLITE_ENABLE_FTS5`），
  FTS5 + trigram 可用，中文子串检索可做；单库 4.76 MB / 11480 仓库。
- **GraphQL 有独立 5000 点/小时，本机完全没用过**。`nodes(ids:[100])` 批量取元数据，
  11480 仓库约 115 批 / 115–230 点，比 REST 逐个（11480 次 core ≈ 3.2h）约 100 倍杠杆。
- **ETag/304 带 Authorization 时不计 primary 配额**（官方 best-practices），但现有 `net.rs:74`
  缓存只在内存 HashMap，重启全失效 → 免费额度吃不到。
- `/events` 官方：**最多 300 条 / 只保留 30 天 / 延迟 30s–6h / X-Poll-Interval 60**。
  只能当候选雷达，绝不能算增长。旧结论「采样 1% / 90 天」作废。
- `stargazers` 列表（2026-07 起限 admin）、`traffic`（401）、`projects`（404）都拿不到。

## 落地：用户侧采集 + 带权重的兴趣画像（用户回「OK，就先这么抓取数据」后授权实施）

需求：采集点开记录；登录态下查自己 star 的仓库、follow 的人；据此分析爱好；各类信号有对应权重。

**实测（真实 token baicaibucai1，scopes=gist/read:org/repo）**：

`/users/{login}/starred` 对别人也可读（phodal 约 3285 个）→ 二阶信号**必须限量**，否则配额爆炸。

**新增/改动**：
- `db.rs` M2 迁移（用户侧 9 张表 + `weight_config` 15 项默认权重）、M3（再加 4 项阈值/系数，共 **19 项**）。
  全部 append-only，旧库 11,480 行一条没动，`schema_version` 现在 3。
- `net.rs`：`get_as()` 支持自定义 Accept；**ETag 缓存键加了 Accept 前缀**（否则 star+json 和 +json 同 URL 会串）。

- 新 `profile.rs`：纯函数，权重合成 + 指数时间衰减 + 归一化（-1..1，负样本能压低词）+ `affinity()`，
  5 个单测；全项目 **14 个单测全绿**。
- 新 `collect.rs`：同步（每人限量 30 条、最多 20 人）、埋点、rebuild、rechannel、profile_view、批量改权重。
- `serve.rs`：新增 `/api/profile`、`/api/profile/sync`、`/api/action`、`/api/weights`(GET/POST)；
  `handle()` 现在**按 Content-Length 读 body**；`/api/profile/sync` 走独立连接，**不持主连接锁**（修报告 D8）；
  feed 把 `affinity` 传进 `rank::score`（之前恒传 0.0）并按结果重排；stats 的曝光/点开率改读真实埋点。
