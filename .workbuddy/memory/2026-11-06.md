**两个必须记住的坑：**

1. **windows-gnu 编译 Tauri 会产出"能生成但加载不了"的 exe**
   - 链接期只有一句 warning：`multiple non-default manifests`
   - 症状：`exit=127`、`CreateProcess` 返回 WinError 2、进程根本不进 `main`
   - 我为此绕了 1 小时（查导入表、逐个 LoadLibrary、加 trace）
   - **正解：必须用 MSVC**。已装 VS 2022 BuildTools(14.44) + `stable-x86_64-pc-windows-msvc`

2. **`include_bytes!` 把 1.5MB 的 seed.db 打进 exe → Defender 直接删文件**
   - 6.4MB 未签名 exe 含大块二进制 = 加壳特征
   - 编译出来还在，跑一次就消失；复制到任何非 target 目录 6~8 秒被删
   - `Add-MpPreference` 加排除需要管理员权限，**当前会话没有**
   - **正解：不内嵌，改成读 exe 同目录的 seed.db**。exe 降到 4.9MB，稳定运行
   - 推论：以后任何"打包数据进 exe"的想法都要先想这一步

**采集上的两个反直觉结论：**

- Search API 用 `sort=stars` 取第一页 == 永远是该语言最高的 100 个。
  条件写宽（`stars:>=50`）没用，中小项目一条进不来。必须按星数区间切三档。
- 取材时**不能**先 `order by score desc limit N` 再分档 —— 高星会把名额占满，
  分档轮转形同虚设。必须每档各自取候选再合并。
