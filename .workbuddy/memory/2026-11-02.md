产物：`docs/proto/app.html`（1180 行单文件，无依赖）+ `docs/proto/README.md`。

### ★★ 两个会导致整页白屏的坑（血泪，务必记住）
1. **顶层裸读 `localStorage`**：预览面板是 `sandbox="allow-scripts"` 的 iframe，读它抛 SecurityError，
   整段脚本不执行 → 白屏。现在统一走 `store.get/set`（try/catch 包住）。
2. **`animation-fill-mode: both` 的入场动画**：沙箱/后台标签页里动画拿不到帧，元素永久停在
   `opacity:0` → 也是白屏。卡片入场动画已删（可见性不能依赖动画）。
3. 附带：`.panel` 用 `translateX(101%)` 停在屏幕外会把文档撑宽（探针实测 scrollW 436 > 430），
   必须包在 `.panelshell{overflow:hidden}` 里。

### 无头截图的自查方法（可复用）
```
msedge --headless=new --disable-gpu --hide-scrollbars --user-data-dir=/tmp/x \
  --force-device-scale-factor=1 --window-size=1000,900 \
  --virtual-time-budget=3500 --screenshot=out.png "file:///...app.html?b=$(date +%s)#/feed"
```
- **必须带唯一的 query 参数**，否则 Edge 会吐同一张旧图（我踩过：三张截图的 md5 完全一样）。
- **`--headless=old` 会把窗口撑到 ~496px**，以为窄屏溢出其实是截图裁切；
  要真窄屏必须用 `--headless=new` + `--force-device-scale-factor=1`（最小约 492px）。
- 页面里留了 `?debug=1`：左下角打印 innerW / scrollW / 最宽元素，排查溢出一次到位。
- 其他调试参数：`?open=7`（详情）、`?pal=1`、`?help=1`、`?q=`、`?lang=`、`?sect=`、`?density=compact`、`?theme=dark`。
