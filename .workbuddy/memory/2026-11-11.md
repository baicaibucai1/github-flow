# 2026-11-11

## 内置本地翻译：看到才翻，纯词典

用户先后三次收窄需求：内置翻译 → 只翻「看到的那条」（否掉全量预烘焙）→ **改成本地词典**，「不需要高质量，可读即可」，但点名两条规则：`win` 不能译成「胜利」、`window` 不能译成「窗户」。

最终形态：`core/src/glossary.rs`（约 3700 行，零依赖零网络）做词典 + 规则翻译，`core/src/translate.rs` 做 markdown 分块与缓存，`tr` 表存译文。

### 关键设计

- **前端 IntersectionObserver（rootMargin 400px）** 只把进视口的卡片推队列，`trLines` 一批 30 条；`TR.memo` 记 key = `id\0字段`，滚回来直接贴。实测首屏 9/9、滚 3 屏 13/13，视口内描述全中文，视口英文 0。
- **一张卡翻三处**：`.body p`（description）、`.cover .rp`（readme_head）、`.cover .rt`（readme_title，≥3 词才翻，项目名单词留着）。封面摘录占整块面积，不翻比描述不翻更显眼。
- **详情面板 `trDetail()`**：`.mdesc` 复用 memo；`.mquote` 是 readme_head 渲染出来的 HTML，得把原文再走一次 `trMd` 后 `teaser()` 重渲染，否则链接丢。
- **README 分块 `Chunk{Keep,Tr,Html}`**：围栏代码块不动；含标签的行交 `html_line()` 只翻标签之间的文字。

### 这一轮踩的坑（都是实测逼出来的）

1. **URL 被打断**：`https://` 的冒号被换成全角 → `HTTPS：//crates.io/...`，全部链接失效。加 `mask_code()` 遮罩行内代码、`](...)` 链接目标、裸 URL，占位符 `⟦cN⟧`。
2. **两套遮罩编号撞车**：图片遮罩 `⟦0⟧` 和代码遮罩 `⟦0⟧` 各从 0 起，把 `[![](a)](b)` 还原成 `[](b)](b)`。代码遮罩前缀改成 `⟦cN⟧`。
3. **`<a href>` 的 a 被当冠词删掉**：整行逐词翻时 `a` → 空，标签变 `< href>`。`split_md` 改成「行里出现 `<`+字母或 `/` 就整行交 `html_line`」，且 `<` 后必须是字母、`/` 或 `!` 才算标签。
4. **`# Deno` 塌成 `#Deno`**：`join_words` 原来只在两侧都是字母数字时补空格。改成看「原句这里有没有空格」，按 `is_cn()` 判断——两个非中文的残留词之间才补；`#` `>` `|` `-` `*` 后面例外，那是 markdown 语法的一部分。
5. **`&amp;` 变 `&amp；`**：分号被换成全角，实体废掉。`tokenize` 里把 `&name;` / `&#nn;` 整块当代码词。
6. **千分位 `2,500` 变 `2，500`**：`cn_punct_at()` 里逗号两侧都是数字时保留 ASCII。
7. **`![` 的感叹号变全角**：`paragraph()` 原来在 `!` 处断句，`!` 成了句末。改成 `!` 后面是 `[` 就不断句。
8. **README 手工折行被逐行翻**：一句话切成三行，主语宾语各翻各的。`split_md` 加续行合并（`starts_structure()` 判标题/列表/表格/引用/有序列表）。
9. **`of` 倒装过头**：`one of two kinds of interface` 倒成「接口的两种类的每个窗口显示一」。改成 >2 段不倒装、前半句 >5 词不倒装（超过 5 词就不是名词短语，是句子）。
10. **单词条写进了 PHRASES 表**：`word_map()` 只读 WORDS，`refreshingly`→`refreshing` 这类词形还原失效。改成 PHRASES 里不带空格的也收进 word_map，WORDS 覆盖。
11. **`in Zig` 永远匹配不上**：键是大写 `Zig`，查表用小写。`phrase_map()` 统一 `to_lowercase()`。

### 部署注意

`frontendDist: "../web"` 说明前端是**编译进 exe** 的，改 `web/*.js` 必须重编。部署后一定用 `Get-FileHash` 比对，这轮又差点验证到旧 exe。exe 在跑时 `Copy-Item` 会 `Device or resource busy`，先 `Stop-Process`。

### 怎么把 app 真正启动起来给用户看（重要）

`Start-Process` 起的 flow.exe 在工具会话结束时会被一起收掉（工具把每次调用放在一个 job object 里，关闭即 kill）。实测 `cmd /c start`、`explorer.exe <exe>`、`Invoke-CimMethod Win32_Process Create` 全被安全策略拦掉（`Add-Type` 也被拦，用不了 PrintWindow 截图）。

**唯一可行：任务计划服务代为启动**，父进程是 svchost，完全脱离当前 job：

```powershell
$act = New-ScheduledTaskAction -Execute "C:\...\dist\Flow\flow.exe" -WorkingDirectory "C:\...\dist\Flow"
$trg = New-ScheduledTaskTrigger -Once -At (Get-Date).AddHours(2)
$prin = New-ScheduledTaskPrincipal -UserId $env:USERNAME -LogonType Interactive -RunLevel Limited
Register-ScheduledTask -TaskName "FlowOnce" -Action $act -Trigger $trg -Principal $prin -Force
Start-ScheduledTask -TaskName "FlowOnce"
Unregister-ScheduledTask -TaskName "FlowOnce" -Confirm:$false   # 任务只是跳板，用完就删
```

`-LogonType Interactive` 必须给，否则窗口在 session 0 里看不见。

截图改用 Python：`from PIL import ImageGrab; ImageGrab.grab(bbox=...)`，配合 ctypes `FindWindowW` + `ShowWindow(9)` + `SetWindowPos(HWND_TOPMOST)` 把窗口顶到前面，否则截到的是 WorkBuddy 自己。

## 第二轮：译文改成「原文 + 下面一行灰字」

用户两条反馈：README 里渲染出一屏 GitHub 用户名（`<!-- clawtributors -->` 注释），以及**不要用译文替换原文**，要每段下面挂灰色小字。后者是产品方向修正——替换版的根本问题是译文一错用户连原句都看不到。

### HTML 注释：三种形态，只有状态机能处理

`md()` 里原来的 `if (/^\s*<!--/.test(line)) continue` 只跳一行。真实 README 里注释有三种写法：

1. `<!-- note -->` 一行闭合
2. `<!-- a` … 十几行 … `-->` 跨行
3. `<!-- a --> <!-- b` … `-->` **一行两个，后一个没闭合**

第 3 种是生成器常见产物（上一段尾注和下一段开头写在一行），按行找 `-->` 会误判成已闭合，后面的用户名就全渲染出来了。正解是循环外维护 `inComment`，逐行扫 `<!--` / `-->` 配对，剥完再解析。代码块里的注释不能动，所以这段放在 fence 判断之后。

### 译文怎么挂

- `trShow(el, text)`：兄弟节点插 `<div class="trsub">`；`li/td/th/h1-h6` 才塞内部（`ul` 里直接跟 div 是非法嵌套）。
- `trHide` / 关开关：`document.querySelectorAll(".trsub").forEach(e=>e.remove())`，一把清干净。
- 卡片描述 `.body > p`、封面 `.rp`/`.rt`、详情 `.mdesc`/`.mquote p` 全走这一套，原文 `textContent` 一个字不动。
- **README 正文不再 `trMd` 整篇替换**，改成 `trReadme(root)`：遍历 `p/li/h1-h4/blockquote/td/th`，只取叶子块（有子列表的 li 跳过），40 条一批调 `trLines`，每块下面插灰字。原文是渲染器产出的，这条路彻底绕开了「翻译改坏 HTML」的所有风险。
- CSS：`.trsub` 基础 `display:-webkit-box` + `-webkit-line-clamp:3`；卡片 2 行、封面 3 行；**README 正文和详情描述改成 `display:block` 不截断**（原文段落本来就不限行数，译文切一半很怪）。
