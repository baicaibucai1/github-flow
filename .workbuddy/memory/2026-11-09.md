## 首次真正编译 exe（14:2x）

`cargo build --release -p flow-app` 通过（22s 增量 / 14s 改后），产物 12MB。GNU 工具链，链接期只有一条无害警告 `.rsrc merge failure: multiple non-default manifests`。

**编译一跑，web 上看不到的问题全暴露了**（预览页的替身把这些都遮住了）：

1. **`ipc.localhost` 被 CSP 拦**。`tauri.conf.json` 的 csp 只有 `default-src 'self'`，没有 `connect-src`，Tauri 的 IPC 走 `http://ipc.localhost/...` 直接 violation，每次都先失败再回退 postMessage。修：csp 加 `connect-src 'self' ipc: http://ipc.localhost`。顺带解释了「第一次点卡浮层没弹」——回退耗时超过 4 秒。
2. **`loading="lazy"` 在 WebView2 里是坏的**。`web/app.js` 两处封面 img（81 行卡片、419 行 README 内图）带 lazy，WebView2 日志明说 "Images loaded lazily and replaced with placeholders"，替换成占位符后再不触发加载：12 张图 `complete:false` 挂到超时，一张不显示。手动 `new Image()` 同样 URL 661ms 就 load 成功，证明网络没问题。修：两处去掉 lazy，保留 `decoding="async" referrerpolicy="no-referrer"`。
3. **`repo_extra` 参数名不匹配**。Tauri 2 默认 `rename_all = camelCase`，前端传 `{full_name}` → 报 `missing required key fullName`，README 和文件树全部落到 `.mfail`。修：`#[tauri::command(rename_all = "snake_case")]`。选改 Rust 不改前端，是因为预览页的替身读的是 `args.full_name`，改前端会把 web 预览一起弄挂。

**分发**：`dist/Flow/` 三个文件必须在同一目录——`flow.exe` + `seed.db` + `WebView2Loader.dll`（GNU 工具链动态依赖，缺它直接退出码 127）。`.gitignore` 已加 `/dist`。

**验证手段**：`WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222` 启动，Node 22 自带 WebSocket 连 CDP 读真实 DOM（`build/cdp.mjs`、`probe2~4.mjs`）。比截图可靠，也避开「不许读图」的约束。
结果：封面 12/12、首屏 40 卡 10 分类、连点 8 张卡 8/8 成功（README 465 段、目录 728 行、零 mfail、零 console error）、文件树「共 1535 个文件，只显示前 90 个」。

## 修「整页发灰」（14:5x）

用户截图里「我的」页整片灰。查下来不是配色问题：`body.dim .main{filter:brightness(.55) saturate(.9);pointer-events:none}` 这个类残留了。dim 本来只在浮层打开期间挂上，而我的验证脚本收尾时直接 `modal.hidden = true` 绕过了 `closeModal()`，类没被摘掉。

- 复测真实路径：点 ✕ 关闭、Esc 关闭，`body.className` 都会清空，`filter:none`。产品逻辑本身没问题。
- 真正的风险在异常路径：dim 带 `pointer-events:none`，一旦残留，主区不光变灰还点不动（侧栏还能点，因为没有这个 filter）。
- 兜底：`renderView()` 开头对账——modal 已 hidden 但 body 还有 dim 就摘掉。切一次视图即自愈，不用重启。

修复后实测：body 空、filter none、hero/card 背景 `rgb(255,255,255)`、标题 `rgb(20,20,20)`、描述 `rgb(92,92,97)`、8 个仓库卡、浮层开关后 body 仍为空。

**教训**：验证脚本也必须走产品自己的关闭路径，不要直接改 `hidden` / 内部状态，否则测出来的"脏状态"会被当成产品缺陷。

## README 渲染补齐（15:00–15:35）

用户截图：整篇 HTML 的 README（justrach/nanoui）被当成源码显示成 `<p align="center">…`。根因是 `md()` 只会「先转义再还原 markdown 结构」，裸 HTML 一律变文本。

- 新增 `sanitizeHtml / sanitizeTag` 白名单通道：标签白名单、属性白名单、`on*` 丢掉、href/src 走 `safeUrl`、**class/id 不放行**（README 里写 `class="card"` 会串到卡片样式和 `closest('.card')` 的事件委托）、script/style/iframe/svg 连内容删。块级标签开头的行按 CommonMark「到空行为止」收集，`pre`/`table` 例外，以闭合标签为准。
- 行内 HTML 在 `inlineMd` 里还原，且必须排在行内代码占位符还原**之前**，否则代码里的 `&lt;br&gt;` 会被当标签。
- 顺带修掉的真 bug：
  - 表格表头渲染成 `---`、首行数据重复进表体（`table.head = cells` 用错了行）；补列对齐与列宽补齐、`splitRow()` 支持 `\|` 和代码里的 `|`。
  - `[文字](url )` 尾部空格的写法认不出来（public-apis 里 4 处），补 `\s*\)`；title 用 `&quot;` 形态也要认。
  - 缩进列表被拍平 → 改成层级栈（bun 328 个 li，最大 2 层），空行不再打断列表。
  - 引用式链接 `[文][key]`、`[![图][a]][b]`、短引用 `[Rust]` 全支持，定义行不显示。
  - `.mquote` 介绍区原来直接 `esc()`，会露出 `[Rust]` → 用 `teaser()` 渲染并抹掉查不到的方括号。
- CSS：`.md img` 必须是 `inline-block`（全局 `img{display:block}` 会把徽章墙压成一行一个、居中失效）；去掉 `max-height:340px`（配 `width` 属性会变形）；`max-width:calc(100% - 8px)` 抵消左右 3px 外边距造成的 6px 横向溢出；`.mtask` 任务框。
- `dropBrokenImgs()`：外链图挂了就 `display:none`，不留破图标。
- `repo_extra` 原来只在登录后用令牌，未登录走匿名（60 次/小时，点十几个仓库就 403）→ 改成先读 `gh` 本机凭据（`OnceLock` 缓存），登录态优先。

测试：`build/mdtest.mjs` 从 `web/app.js` 切出 md/sanitizeHtml/teaser 单跑，7 组 50 项断言全绿（含 15 条注入用例、代码块不误伤、表格/列表/引用回归）。真机 CDP 实测：nanoui 22/22 图、19 个居中块、0 残留转义；bun 列表 2 层 328 项；rust 引用链接与短引用全部解析；public-apis 54 表 2584 链接、0 残留 `](`。

**教训**：`tasklist` 显示进程消失 + `taskkill` 混在每条命令开头，会把「我自己杀掉的进程」误判成自退出；用调试端口起的实例也不稳定。加心跳日志实测 50 秒无 CloseRequested，确认是测试副作用。
