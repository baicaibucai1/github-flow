## github-flow-v2：发现页改成小红书式瀑布流卡片

项目 `C:\AI_Project_2\github-flow-v2`（Rust core + Tauri 2 + 无框架前端）。这一轮只动 `web/` 三个文件，Rust 侧没碰。

### 改了什么
- `web/api.js`：`feed()` 不再返回 `sections`，改成返回平铺 `items` + `channels`（含每格数量）。
  四条通道按 `MIX = hot3 : profile2 : social2 : explore1` 的权重轮流取，推荐位不再被热度榜独占。
- `web/app.js`：
  - 新增 `poster()`——每张封面是按项目**自己的周曲线**画的 SVG 海报（三种画法：柱+线+面积 / 纯柱 / 线+点），
    比例从 `ARS` 五档里按名字散列取，约 1/4 走深色版；左下压「+N star / 周」，右下角语言，左上频道药丸。
  - 色相：`PAL` 12 个固定色相，按 `id*5` 取，保证相邻卡片不同色（用 `raw(name)%360` 会撞出一堆分不开的灰紫）。
  - `distribute() + waterfall()`：按 `100/ar + 96` 估高，贪心分到最矮的列，**按行读但列高齐**（CSS columns 会是列优先，顺序错）。
  - 频道从「分节标题」变成顶部 tabs；搜索框改成胶囊并和 tabs 同一行吸顶（`top:56px`）。
  - 收藏/不感兴趣改成 `render({keep:true})`，不再跳回顶部。
- `web/style.css`：`.wf/.wfcol/.rn/.rcv/...` 一整套；删掉 `.cardx/.sec/.chart/.qb` 旧样式，保留 `.face/.sub/.row`。

### 调试姿势（下次直接用）
- 预览：`python -m http.server 8791 --bind 127.0.0.1`（**必须 run_in_background**，nohup 起的会在 shell 退出时被杀）。
- 截图：`msedge.exe --headless=new --screenshot=... --window-size=1080,760 --user-data-dir=<新目录> --virtual-time-budget=5000 "http://127.0.0.1:8791/index.html?demo=1&v=N"`。
  - 每张图都要换 `--user-data-dir` 和 `?v=`，否则拿到缓存图。
  - **headless 下 CSS transition 不推进**：面板/遮罩会停在起点。为此加了 `?noanim=1`（`html[data-noanim]` 关过渡）。
  - **headless 下 JS 滚动会「双重偏移」**：内容整体下移 scrollY、顶部留白。别用它验吸顶，会看到假 bug。
  - 整页看布局：`--window-size=1080,2900` 直接截全高，比滚动可靠。
- 打包：`cargo build --release -p github-flow`，约 1 分半；前端在编译期嵌进 exe（`frontendDist: ../web`），
  **改完 web 必须重编**。产物 `target/release/github-flow.exe`（6.5MB）。
  exe 里的前端是压缩存储的，`grep wfcol github-flow.exe` 查不到属正常，别据此判断没嵌进去。
